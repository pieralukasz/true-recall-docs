## Install in 2 Minutes
</div>

<Steps>
1. **Download Obsidian**: get it free from [obsidian.md](https://obsidian.md) and create a vault

2. **Install True Recall**: open `Settings → Community plugins → Browse`, search for **True Recall**, and click **Install**

3. **Enable True Recall**: toggle it on in `Settings → Community plugins`

4. **Start creating cards**: select text in any note, click **Ask AI** in the Quick Actions Toolbar, and the AI Workspace drafts flashcards for you to review before anything is saved
</Steps>

Available directly in the [Obsidian Community Plugins](https://community.obsidian.md/plugins/true-recall) directory, no BRAT or manual install needed. Works on desktop, iOS, and Android.
